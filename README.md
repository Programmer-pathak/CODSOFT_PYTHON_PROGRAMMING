# 🐍 CodSoft Python Programming Internship

This repository contains Python projects completed as part of my **Python Programming Internship at CodSoft**.

The projects focus on strengthening fundamental Python programming concepts including loops, conditional statements, functions, lists, exception handling, input validation, and working with Python's standard library.

---

## 👨‍💻 Internship Projects

### 📝 Task 1 — To-Do List Application

A command-line task management application that allows users to:

* Add tasks
* View tasks
* Update existing tasks
* Delete tasks
* Handle invalid inputs

**Concepts Used:** Python Lists, Loops, `match-case`, Conditional Statements, `enumerate()`, Exception Handling, Input Validation

---

### 🧮 Task 2 — Simple Calculator

A command-line calculator capable of performing basic arithmetic operations.

The calculator supports:

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero handling
* Invalid numeric input handling
* Multiple calculations in a single program session

**Concepts Used:** Arithmetic Operators, Loops, `match-case`, Conditional Statements, `try-except`, User Input

---

### 🔐 Task 3 — Password Generator

A customizable command-line password generator that allows users to select:

* Password length
* Uppercase letters
* Lowercase letters
* Numbers
* Symbols

The project uses Python's `secrets` module for secure random character selection.

**Concepts Used:** Functions, Loops, Lists, Input Validation, `string` Module, `secrets` Module, Exception Handling

## ▶️ Running the Projects

### Clone the repository

```bash
git clone https://github.com/Programmer-pathak/CODSOFT_PYTHON_PROGRAMMING.git
```

### Open the repository

```bash
cd CODSOFT_PYTHON_PROGRAMMING
```

Open the required task folder and run its Python file.

For example:

```bash
cd Task_1_To_Do_List
python todo_list.py
```

> Some projects use `match-case`, so Python 3.10 or later is recommended.
