# To-Do List Application

A command-line To-Do List application built using Python as part of the CodSoft Python Programming Internship.

## Features

* Add tasks
* View tasks
* Update tasks
* Delete tasks
* Input validation
* Error handling for invalid task numbers

## Technologies Used

* Python

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python todo_list.py
```
